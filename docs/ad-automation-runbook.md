## Password Policy (configured via GPO in lab)

| Setting | Value |
|---------|-------|
| Minimum password length | 10 characters |
| Password complexity | Enabled |
| Password history | 12 passwords remembered |
| Maximum password age | 90 days |
| Minimum password age | 1 day |
| Account lockout threshold | 5 failed attempts |
| Lockout observation window | 30 minutes |
| Lockout duration | 30 minutes |

The temporary passwords generated by Reset-ADUserPassword.ps1 are designed to meet
this policy (12 chars, upper + lower + digit + symbol).

## Testing Script Changes

Before running any script in a production domain, test in the lab:

1. Create a test OU: `New-ADOrganizationalUnit -Name "Test" -Path "DC=contoso,DC=local"`
2. Create a test user manually for reset/unlock testing
3. Run the script targeting the test OU or test user
4. Verify the log output and console output match expected behaviour
5. Verify in ADUC that the user was created/modified/disabled correctly
6. Delete the test OU when testing is complete

## Extending the Ticket Intake Tool

To add a new issue type to `ticket_intake.py`:

1. Open `scripts/ticket-intake/ticket_intake.py`
2. Add a new key to the `RESOLUTIONS` dictionary
3. Follow the same structure: `category`, `priority`, `sla_response`, `sla_resolution`, `steps` (list), `escalate_if`
4. The key is the keyword that will be matched in the caller's issue description
5. Test: run the tool and type the keyword in the issue description field

Example addition (adding "bluetooth" as a new category):
```python
"bluetooth": {
    "category"       : "Hardware — Bluetooth / Wireless Peripheral",
    "priority"       : "P3 — Medium",
    "sla_response"   : "4 hours",
    "sla_resolution" : "24 hours",
    "steps": [
        "Toggle Bluetooth off and back on: Settings > Devices > Bluetooth.",
        "Remove and re-pair the device: Remove device > Add Bluetooth device.",
        "Check Device Manager for Bluetooth adapter errors (yellow exclamation).",
        "Update Bluetooth adapter driver via Device Manager > Update Driver.",
        "Test with a different Bluetooth device to isolate whether the issue is "
        "the adapter (affects all devices) or the specific peripheral.",
    ],
    "escalate_if": "Bluetooth adapter missing from Device Manager entirely — "
